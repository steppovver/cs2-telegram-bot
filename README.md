# CS2 Telegram Bot

Telegram-бот расписания матчей CS2: подписки на команды, уведомления о новых матчах,
переносах и старте игр, напоминания перед началом и утренний дайджест.

**Бот:** https://t.me/cs2_tracker_telegram_bot

## Для пользователей

### Как начать

1. Откройте https://t.me/cs2_tracker_telegram_bot и нажмите `Start`.
2. Выберите действие в меню внизу экрана.

### Кнопки меню

| Кнопка | Что делает |
|---|---|
| 📅 Узнать расписание | Live-матчи ваших команд, ближайшие (24 часа) и предстоящие |
| 📊 Счет матчей | Счет идущих и недавних завершенных матчей (без спойлеров в уведомлениях) |
| 🔔 Подписки на команды | Включение/выключение уведомлений по командам (нужной нет в списке — введи часть названия в чат) |
| 🏆 Подписки на турниры | Подписка на плей-офф турниров, где играют или играли ваши команды |
| ⏰ Дайджест | Ежедневная подборка матчей на 24 часа в выбранный час |

### Уведомления

- 🆕 новый матч вашей команды;
- ⚠️ перенос времени матча;
- 🔴 матч начался;
- 🔥 напоминание за 5 минут до начала;
- ⏰ дайджест (если включен).

По подписанным турнирам приходит только «🔴 матч начался» для матчей плей-офф.

Время везде показывается в вашем часовом поясе. Пояс меняется в настройках
дайджеста (кнопка `🌍 UTC±N` или «Свой пояс»).

### ⏰ Дайджест

Дайджест — одно сообщение утром: какие матчи ваших команд пройдут
в ближайшие 24 часа. Ваши команды в списке выделены жирным.

Как включить:

1. Нажмите `⏰ Дайджест` в меню.
2. Нажмите `✅ Включить`.
3. Выберите час кнопкой (например, `10:00`) или «Свой час» — введите час
   от 0 до 23 **по вашему местному времени**.
4. Проверьте пояс: кнопка `🌍 UTC±N` или «Свой пояс» (например, Москва — `+3`).

Что важно знать:

- приходит раз в день в выбранный час;
- если матчей ваших команд в ближайшие сутки нет — бот промолчит,
  это нормально, а не ошибка;
- учитываются команды из ваших подписок, а плей-офф подписанных турниров —
  если в `🏆 Подписки на турниры` выбран показ турнирных матчей по умолчанию.

### 🏆 Подписки на турниры

Если ваши команды вылетели, а следить за турниром все равно интересно,
подпишитесь на него. В списке только турниры, где ваши команды уже сыграли,
играют сейчас или сыграют позже. Закончившийся турнир пропадает из списка
через сутки, а через неделю бот сам удаляет подписку на него.

- Отслеживается только плей-офф: групповые стадии дают слишком много матчей.
- В `📅 Узнать расписание` и `📊 Счет матчей` турнирные матчи по умолчанию
  скрыты; под ответом есть кнопка «🏆 Показать турнирные матчи (N)»
  и обратная «🙈 Скрыть турнирные матчи».
- Последняя кнопка меню турниров меняет режим по умолчанию: показывать
  все матчи турниров сразу или только матчи ваших команд.
- Из уведомлений по турнирным матчам приходит только «🔴 матч начался».

### Частые вопросы

- **Не приходят уведомления** — проверьте подписки (`🔔 Подписки на команды`)
  и что бот не заблокирован: разблокируйте и нажмите `/start`.
- **Неправильное время** — выставьте свой часовой пояс в `⏰ Дайджест`.
- **Дайджест не пришёл** — проверьте, что он включен (`⏰ Дайджест` → статус),
  и что у ваших команд есть матчи в ближайшие сутки. Пустой дайджест не присылается.
- **Нет нужной команды** — введи часть названия в чат, бот найдет и предложит подписаться.
- **Нашли баг** — напишите в поддержку (раздел ниже).

## Для разработчиков

### Требования

- Go 1.25+
- `sqlite3` (только для бэкапов на сервере, сам бот на pure-Go драйвере)
- `nfpm` — для сборки `.deb` (`go install github.com/goreleaser/nfpm/v2/cmd/nfpm@latest`)

### Быстрый старт

```bash
cp config_example.json config.json
# вписать telegram_token и pandascore_token (см. таблицу ниже)
go run ./cmd/bot
```

Токены:

- Telegram — получить у [@BotFather](https://t.me/BotFather);
- PandaScore — личный кабинет на [pandascore.co](https://pandascore.co).

### Конфигурация (`config.json`)

| Поле | Назначение |
|---|---|
| `telegram_token` | Токен бота от BotFather |
| `pandascore_token` | Токен PandaScore API |
| `db_path` | Путь к SQLite-базе (по умолчанию `bot.db`) |
| `debug` | Подробные логи (`false` на проде) |
| `digest_preset_hours` | Пресеты часа дайджеста для кнопок |
| `default_teams` | Команды, показываемые в подписках по умолчанию |
| `admin_ids` | Telegram ID администраторов (узнать: [@userinfobot](https://t.me/userinfobot)) |
| `max_streams_per_match` | Макс. неофициальных стримов в `📺 Смотреть` (`0` = все, дефолт `0`, cap 10; официальные в `⭐` всегда все) |
| `poll_interval_seconds` | Запасной период опроса матчей PandaScore в секундах (дефолт `60`, границы 15–3600): пока нет заголовка лимита, опрашивать некого или динамика выключена. Динамика (темп 50% лимита в час) выключается при остатке ≤ 40% и снова включается только когда остаток > 50% |
| `finished_poll_interval_seconds` | Период добора завершенных матчей для кнопки `📊` в секундах (дефолт `120`, границы 60–86400) |
| `api_rate_limit_per_hour` | Лимит REST-запросов PandaScore в час для темпа опроса и статистики (дефолт `1000`) |
| `search_provider` | Поиск точных ссылок на матчи HLTV за 12 часов до старта: `ddg` (дефолт, DuckDuckGo без ключа), `searxng` или `none` (только поиск Google) |
| `search_base_url` | Адрес своего инстанса SearXNG, нужен только для `search_provider=searxng` |
| `telegram_mode` | Способ получения апдейтов Telegram: `polling` (дефолт) или `webhook` |
| `webhook_public_url` | Публичный HTTPS-адрес вебхука, например `https://cs2bot.example.com/tg` (обязателен при `telegram_mode=webhook`) |
| `webhook_listen` | Локальный адрес HTTP-сервера за reverse proxy (дефолт `127.0.0.1:18090`) |
| `webhook_secret` | Секрет заголовка `X-Telegram-Bot-Api-Secret-Token` (обязателен при webhook; `openssl rand -hex 32`) |

Секреты (`config.json`, `.env`) в git не коммитятся, см. `.gitignore`.
Пример деплойных переменных — в `.env.example`.

### Режим webhook (опционально)

По умолчанию бот работает через long polling — публичный адрес не нужен.
Webhook удобен, если апдейты должны приходить push’ем за reverse proxy
(отдельный поддомен + TLS). Пример блока Caddy — `deploy/Caddyfile.cs2bot.example`.

Кратко на сервере:

1. DNS A-запись поддомена на IP сервера (DNS only, без Cloudflare-прокси).
2. `CS2BOT_HOSTNAME=<поддомен>` в окружении Caddy, дописать блок из примера в `Caddyfile`, `systemctl reload caddy`.
3. В `config.json`: `telegram_mode=webhook`, `webhook_public_url=https://<поддомен>/tg`,
   `webhook_listen=127.0.0.1:18090`, `webhook_secret` из `openssl rand -hex 32`.
4. Перед стартом: `ss -ltnp | grep 18090` (вывод должен быть пустым), затем рестарт `cs2bot`.

При обратном переключении на `polling` бот сам снимает webhook у Telegram.

### Справочник команд (`teams_puller`)

Команды и составы меняются редко, поэтому справочник обновляется отдельно:

```bash
go run ./cmd/teams_puller
```

Данные кладутся в те же таблицы `teams`/`players`, которые читает бот.
Команды без игроков в каталог не добавляются. Если команда пропала из ответа
API, строка и подписка на неё удаляются. На сервере тот же бинарь запускает
systemd timer `cs2bot-teams-puller.timer` раз в сутки в 05:00.

## Деплой

Пакет `.deb` ставит бинари, юниты и скрипт бэкапа. Конфиг (`/etc/cs2bot/config.json`)
пакет **не владеет** и при обновлении не перезаписывает.

Раскладка на сервере:

| Путь | Назначение |
|---|---|
| `/opt/cs2bot/bin/` | `cs2bot`, `teams_puller`, `cs2bot-backup` |
| `/usr/bin/cs2bot` и др. | симлинки на бинари |
| `/etc/cs2bot/config.json` | конфиг (`0640`, `root:cs2bot`) |
| `/var/lib/cs2bot/bot.db` | SQLite (домашний каталог пользователя `cs2bot`) |
| `/var/lib/cs2bot/backups/` | архивы БД (`0700`) |
| `/usr/share/doc/cs2bot/examples/` | свежие примеры конфига и Caddyfile |

### Подготовка

```bash
cp .env.example .env
# заполнить DEPLOY_USER / DEPLOY_HOST / DEPLOY_PORT
# для сборки .deb нужен nfpm: go install github.com/goreleaser/nfpm/v2/cmd/nfpm@latest
```

### Первичная установка

```bash
# локально
bash deploy/build-deb.sh
scp -P 22 dist/cs2bot_*.deb root@HOST:/tmp/

# на сервере
apt install -y /tmp/cs2bot_*.deb
# отредактировать токены
nano /etc/cs2bot/config.json
systemctl enable --now cs2bot
systemctl status cs2bot
```

`postinst` создаёт системного пользователя `cs2bot`, каталоги и включает
`cs2bot-teams-puller.timer` (05:00) и `cs2bot-backup.timer` (04:00).
Если конфига ещё не было — копирует пример и **не** включает бота,
пока не впишете токены. Если конфиг уже есть — включает и перезапускает `cs2bot`.

### Обновления

```bash
bash deploy/deploy.sh
```

Скрипт собирает `.deb` (версия из git-тега/коммита), копирует в
`/var/cache/cs2bot-debs/` на сервере и ставит через `apt install`.
Перед распаковкой `preinst` останавливает сервис и делает predeploy-бэкап БД.
Конфиг не трогается. На сервере хранятся 3 последних `.deb` для отката.

Проверка после деплоя:

```bash
ssh -p 22 root@HOST "systemctl is-active cs2bot && journalctl -u cs2bot -n 20 --no-pager"
```

### Откат пакета

```bash
ssh -p 22 root@HOST "ls -1t /var/cache/cs2bot-debs/cs2bot_*.deb"
ssh -p 22 root@HOST "apt install --allow-downgrades -y /var/cache/cs2bot-debs/cs2bot_<prev>_amd64.deb"
```

### Восстановление БД из бэкапа

```bash
ssh -p 22 root@HOST '
  systemctl stop cs2bot cs2bot-teams-puller.timer cs2bot-teams-puller.service
  cd /var/lib/cs2bot
  # обязательно убрать sidecar WAL, иначе SQLite накатит его поверх снимка
  rm -f bot.db-wal bot.db-shm
  gzip -dc backups/bot-YYYY-MM-DD-HHMMSS.db.gz > bot.db
  chown cs2bot:cs2bot bot.db
  systemctl start cs2bot cs2bot-teams-puller.timer
  systemctl is-active cs2bot
'
```

## Админка

Доступ — по `admin_ids` из конфига. Чужим на команды тишина.

- `/admin` — панель: `📊 Статистика` (пользователи, подписки, матчи в БД,
  остаток лимита PandaScore и режим опроса, версия), `🔖 Версия`.
- При падении остатка лимита на ≤ 40% всем `admin_ids` уходит одно сообщение;
  опрос на `poll_interval_seconds`, пока остаток снова не станет > 50%.
- `/version` — шорткат: версия сборки без открытия панели.
- `cs2bot --version` — версия локального бинаря без запуска.

## Архитектура

```
cmd/bot            точка входа бота
cmd/teams_puller   наполнение справочника команд
internal/bot       хендлеры, воркеры (поллер, напоминания, рассылка, дайджест), админка, telegram_poller
internal/api       клиент PandaScore (чанки, ретраи, пагинация)
internal/hltv      поиск и резолв точных ссылок на матчи HLTV
internal/youtube   oEmbed: резолв имен YouTube-каналов для подписей стримов
internal/storage   SQLite: схема, миграции, подписки на команды и турниры, матчи, дайджесты, кеш stream_channels
internal/config    загрузка и нормализация config.json
internal/domain    доменные модели
deploy/            nfpm.yaml, build-deb.sh, deploy.sh, debian/*, systemd-юниты, cs2bot-backup
```

- Хранилище — SQLite в WAL-режиме, на проде файл `/var/lib/cs2bot/bot.db`.
- Деплой — пакет `.deb` (`deploy/build-deb.sh` / `deploy/deploy.sh`); бэкап БД —
  systemd timer `cs2bot-backup.timer` (ежедневно 04:00).
- Telegram — long polling или webhook (`telegram_mode`), только **один инстанс** на токен.
- Воркеры: опрос live/предстоящих матчей с динамическим темпом (50% лимита
  PandaScore в час; выключение при остатке ≤ 40%, включение при > 50%),
  добор завершенных по `finished_poll_interval_seconds`. Оба опроса, кроме
  матчей подписанных команд, запрашивают матчи активных подписанных турниров
  (`filter[serie_id]`, плей-офф определяется по стадии) — это дополнительные
  запросы к лимиту, их учитывает динамический темп. Связь «турнир ↔ команда»
  хранится в `tournament_teams` отдельно от матчей и чистится через 7 дней после
  окончания турнира вместе с `tournament_subscriptions`. Напоминания каждую
  минуту (окно 5 минут), дайджест каждую минуту, рассылка через очередь
  (лимит ~25 msg/sec, чистка заблокировавших бота, пауза по FloodWait).
- Резолвер HLTV — точные ссылки на страницы матчей (за 12 часов до старта,
  провайдер из `search_provider`).
- Резолвер YouTube — имена каналов через oEmbed каждые 5 минут
  (окно `[-6h, +48h]`), результат в `stream_channels`; расписание, напоминания,
  дайджест и события поллера читают только кеш БД.
