# Проект cs2-telegram-bot

Telegram-бот на Go для отслеживания матчей Counter-Strike 2 с использованием SQLite и PandaScore API.

## Стек и архитектура
- **Язык**: Go (актуальная версия из `go.mod`)
- **База данных**: SQLite (драйвер `modernc.org/sqlite` или `mattn/go-sqlite3`)
- **API**: PandaScore API
- **Архитектура**:
  - `cmd/bot/main.go` — точка входа для бота
  - `cmd/teams_puller/main.go` — утилита синхронизации команд
  - `internal/api/` — клиенты внешних API (PandaScore)
  - `internal/bot/` — обработчики Telegram (handlers, workers)
  - `internal/domain/` — доменные модели и интерфейсы
  - `internal/storage/` — слой работы с базой данных (SQLite)

## Правила кодогенерации
1. **Обработка ошибок**: Явная обработка через `if err != nil`, оборачивание с контекстом (`fmt.Errorf("...: %w", err)`).
2. **Конкурентность**: Использование контекстов (`context.Context`), отслеживание утечек горутин и правильное закрытие соединений (`defer`).
3. **Форматирование и тесты**: 
   - Всегда проверяй синтаксис через `go vet ./...`.
   - Запускай `go test ./...` перед завершением задачи.
   - Не изменяй миграции базы данных без явного подтверждения.

## Автономный цикл проверки
После внесения любых изменений в код (.go файлы) ты ОБЯЗАН:
1. Запустить `go vet ./...`
2. Запустить `go build ./cmd/bot`
3. Если возникли ошибки компиляции — проанализируй вывод терминала, исправь код и повтори сборку.
4. Отдавай финальный ответ только после успешного завершения сборки.
